# multistore-platform
A full-stack multi-vendor store directory and customer review platform built with React, Express, Prisma, and Tailwind CSS.
# 🛍️ MultiStore – Store Directory & Review Platform

MultiStore ek full-stack multi-vendor store directory aur customer review platform hai. Isme store owners apni storefronts customize kar sakte hain, aur customers alag-alag categories ke stores ko discover karke genuine reviews de sakte hain.

---

## 🚀 Features

- **Multi-Vendor Architecture**: Store owners apne stores list kar sakte hain aur branding customize kar sakte hain.
- **Central Review Dashboard**: Sabhi stores ke reviews ek jagah manage aur filter karne ki suvidha.
- **Category Browsing**: Books, Electronics, Fashion, Grocery jaise categories me stores discover karein.
- **Role-Based Access**: Super Admin, Store Owner, aur Customer roles.
- **Analytics & Stats**: Platform rating, total reviews, aur owner response rate tracking.

---

## 🛠️ Tech Stack

- **Frontend**: React, Vite, TypeScript, Tailwind CSS
- **Backend**: Node.js, Express.js
- **Database & ORM**: SQLite, Prisma ORM
